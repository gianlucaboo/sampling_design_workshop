AI and ML in sampling

  • Improve sampling efficiency and representativeness
  • Detect patterns in complex population data
  • Reduce bias and improve stratification
  • Reduce sample size while maintaining accuracy

Overview of ML

Supervised learning: prediction based on known outcomes
Unsupervised learning: finding patterns/clusters without labeled outcomes

ML workflow

  1. Training
  2. Validation
  3. Prediction

K-means clustering

  • Unsupervised learning method
  • Detect natural groups in population data
  • Useful for creating representative samples
  • Minimize within-cluster variance

K-means in R (clustering)

library(tidymodels); library(tidyverse)

# Remove species column
data <- iris |> select(-Species)
  
# K-means clustering with k=3
kmeans_fit <- kmeans(scale(data), centers = 3)

data <- data |> 
  mutate(Cluster = kmeans_fit$cluster,
         Species = iris$Species)

ggplot(data, aes(x=Sepal.Length, y=Sepal.Width, color=factor(Cluster))) +
  geom_point(size=3) +
  theme_minimal() +
  labs(color="Cluster")

ℹ️ Try to run with 4 or 5 clusters.

Random forest

  • Decision trees: easy to interpret but can overfit
  • Bagging: bootstrap sampling builds diverse trees
  • Random feature selection: reduces correlation among trees
  • Voting/averaging: improves accuracy

Random forest in R

library(tidymodels)

# Split data
set.seed(123)
data_split <- initial_split(iris |> select(-Species), prop = 0.8)
train <- training(data_split)
test <- testing(data_split)

# Define recipe and model
rf_recipe <- recipe(Petal.Length ~ ., data = train)

rf_model <- rand_forest(trees = 500) |> 
  set_engine("ranger", importance = "permutation") |> 
  set_mode("regression")

Training the random forest

rf_wf <- workflow() |> 
  add_recipe(rf_recipe) |> 
  add_model(rf_model)

rf_fit <- rf_wf |> fit(data = train)

rf_preds <- predict(rf_fit, test) |> bind_cols(test)

Evaluating performance

rf_preds |> metrics(truth = Petal.Length, estimate = .pred)
  • RMSE: root mean squared error (lower = better)
  • R²: proportion of variance explained (higher = better)

Variable importance

library(vip)

rf_fit |> extract_fit_parsnip() |> vip(num_features = 3)

Introducing tidymodels

  • A collection of R packages for modeling and machine learning
  • Provides a consistent grammar for:
    • Preprocessing (recipes)
    • Model specification (parsnip)
    • Tuning (tune)
    • Resampling (rsample)
    • Evaluation (yardstick)

tidymodels workflow

library(tidymodels)

# Example workflow: linear regression
lm_recipe <- recipe(Petal.Length ~ Sepal.Length + Sepal.Width, data = iris)

lm_model <- linear_reg() |> set_engine("lm")

lm_wf <- workflow() |> add_recipe(lm_recipe) |> add_model(lm_model)

Resampling with rsample

set.seed(123)
cv_folds <- vfold_cv(iris, v = 5)

cv_folds
  • Splits the data into training and validation folds
  • Useful for model evaluation and tuning

Hyperparameter tuning with tune

rf_tune <- rand_forest(mtry = tune(), trees = 500, min_n = tune()) |> 
  set_engine("ranger") |> 
  set_mode("regression")

rf_grid <- grid_regular(mtry(range = c(1,4)), min_n(), levels = 3)

rf_tuned <- tune_grid(
  workflow() |> add_recipe(rf_recipe) |> add_model(rf_tune),
  resamples = cv_folds,
  grid = rf_grid
)
